# AirDraw

AirDraw is a gesture-controlled virtual drawing application built using Python, OpenCV, and MediaPipe.
Instead of using a mouse or touchscreen, users can draw in the air using hand gestures detected through a webcam.

The project combines computer vision, real-time hand tracking, UI interaction, and visual effects to create an interactive touchless painting experience.

# Features 

* Real-time hand tracking using MediaPipe
* Air drawing using finger gestures
* RGB color selection
* Thin and thick brush modes
* Glow effect mode
* Rainbow drawing mode
* Smooth drawing interpolation
* Motion trail effects
* Gesture-controlled UI
* Sound feedback for interactions
* Fist gesture to clear canvas
* Dynamic status notifications
* Fullscreen webcam canvas experience


# Technologies Used

# How to Run 

Run the Python file:

```bash
python AirDraw.py
```

Press `Q` anytime to quit the application.


# Controls 

## Drawing

* Raise only your **index finger** to draw.

## Button Selection

* Raise **index + middle finger** together and hover over a button.

## Clear Canvas

* Make a **fist gesture** to clear the screen.

# Available Modes 

## RGB Colors

Choose between:

* Red
* Green
* Blue

## Brush Sizes

* Thin Brush
* Thick Brush

## Glow Mode

Adds a glowing neon effect to drawings.

## Rainbow Mode

Cycles through rainbow colors automatically while drawing.
